RegEngine connection

Sandbox

This is where events go. Sandbox needs no setup — it behaves like RegEngine, including rejections. To connect your real RegEngine workspace:

  1. Paste the ingest endpoint, API key, and tenant ID from your RegEngine workspace below.
  2. Click Test connection — the verdict tells you exactly what to fix if something's wrong.
  3. Click Save settings, then switch Delivery to Connected.
